As a forward deployed engineer at Meta, I spent the past 2 years working with businesses implementing AI agents.A few problems: 1) Businesses want control over their AI agents: the code, the tools, the skills, everything. Meta, for obvious reasons would never do that. Nor OpenAI, nor Anthropic. 2) The LLM does everything. But that costs money. There are many routines in an AI agents that don't need an LLM. 3) For an AI agent to solve a real business problem, the business must own the eval data set. Similar to point #1 above, most don't do that.Instead, I built an opensource AI agent that you can write it all in TypeScript code and own everything, locally. Use any model, talk to it via any channels, set limits on token usage, look at the logs and adjust. All of this in one small npm package.At this point, I would like to get feedback if these is a gap in the market for something like this. It's supposed to be simple and get you started. It doesn't solve ALL problems related to deploying AI agents.
