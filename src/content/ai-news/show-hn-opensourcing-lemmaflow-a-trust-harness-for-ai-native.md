Hi HN, I am introducing Lemmaflow (https://github.com/lemmaflow/lemmaflow) - an open source harness to build & production applications with trust.We all are using AI to ship applications but most of the time the app itself is not safe for the end user. It might leak data, it might violate GDPR, it might ignore cookies.The trust problem is the primary reason why there's still a huge gap in what can be shipped by an experienced dev with AI vs one who is just vibecoding.Lemmaflow tries to cut this gap by introducing a set of 200+ implementable policies and run audits and tell Claude to exactly build trustworthy apps.Do give this a try.
