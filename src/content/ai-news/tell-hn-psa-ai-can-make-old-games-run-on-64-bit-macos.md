I had Aviary Attorney lying around (great game, whether or not you like Phoenix Wright) but it wouldn't run on newer macOS versions.I tried asking Astra on a whim, looked away, and within a few minutes it was on screen!Turns out "The game used 32-bit Node-WebKit, an old combination of Node.js and Chromium that modern macOS cannot run. Its actual game content was HTML, JavaScript, images, and audio, so replacing the runtime was feasible."Guess I got lucky in this case.
