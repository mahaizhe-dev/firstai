... or has it encouraged you to upgrade?I'm still using an 8th gen i7 (w/ linux) for most of my dev work. I was going to upgrade, but now I just run like 10 terminal tabs instead of IDEs. Concurrent builds even w/ Rust and Java usually aren't a big issue. I have several backup machines so if it dies, not a big deal. If I need to, I can just tell Claude "do all builds on and iterate via CI"The benefit is for things like FastComments, I get immediate feedback if the interface is slow vs waiting for regression checks.The downside is apps like Stripe are seriously slow in FF on this machine, for some reason, despite the fact that it can play a 3d game like RDD 2 at 60fps.
