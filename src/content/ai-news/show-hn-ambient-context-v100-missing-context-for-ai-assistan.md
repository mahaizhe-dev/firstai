The other week I posted a concept to use the macOS Accessibility API to capture the text on your screen into a markdown file. It seemed to be interesting with 150+ github stars.I've done a bunch of updates and packaged them into a signed macOS app.One of the biggest changes was moving away from 'one context file per day' to three markdown files for apps, website, and messages.I then run Andrej Karpathy's LLM Wiki process to turn into a simple knowledge base for the day.
