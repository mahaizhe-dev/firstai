Hey HN, I'm Raymond, a long-time reader of the site.For the past year I've been working on Animama, a free and open-source (AGPL) AI desktop companion with 3D anime-style avatars.A quick rundown of the Anima (AI companion) features:- Personality: an IDENTITY.md file you can edit- Memories: a memory filesystem of Markdown files. Animas have tools to read and write these files, and you can edit them too- Emotions: Animas can express 24 emotions, which drive their facial expressions, tone of voice and behavior- Behavior: 300+ gestures and reactions, built on a custom JSON animation format (animaPoseClip)- Structured output: every reply is text plus an emotion and a gesture, which the avatar acts out as it speaksYou bring your own API key. The low-cost models from OpenAI (GPT-6 Luna) and Anthropic (Claude Haiku 5.5) are good enough, so a few dollars of usage goes a long way. Local models are supported but still experimental.When I started, pretty much all human-AI interaction was typing into a chat box and getting a wall of text back. I felt this could be made more engaging, interactive and fun. Like everything else in AI, things have improved a lot since then. We now have speech-to-speech models (GPT Live, Gemini Realtime), and even the frontier labs have released their own AI avatars (Codex pets, Grok's Ani). Animama is just one solo developer's take on it.My original idea was an AI productivity companion (think Clippy, RIP), and it still kind of is. But it's obviously never going to compete with the Claude and ChatGPT desktop apps, so I leaned more into the character side of things.Anyways, I built this because I thought it would be a fun project. But, it did make me realize that there are some serious risks to AI Companion apps, so I've made the app 18+ with safety guardrails built in (e.g. an Anima admits it's an AI if you sincerely ask).Three ways to try it:1. Desktop app (Apple silicon Mac, Windows 11, linux and windows 10 coming soon): https://animama.ai/download2. Self-host with Docker: see the README3.
